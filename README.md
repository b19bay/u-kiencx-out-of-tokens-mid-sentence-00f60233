The funniest one-line error message an AI agent shows when it runs out of tokens mid-sentence. The error message itself turns into the joke: the token budget is exhausted, so the rest of the message has been repossessed to cover the debt.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=/tmp/out node --experimental-strip-types main.ts
```

This writes a single line to `/tmp/out/entry.txt`:

> Error: token budget exhausted mid-sentence. The rest of this message has been repossessed to cover the debt.
